### Как воспроизвести

В корне репозитория выполнить `npm ci`, `npm run build` и `node scripts/tests/public-build.mjs`. Для тестов требуются Node 22+, PHP с curl и mbstring, доступный по команде `php`, jsdom, playwright-core и соответствующий Chromium. В workflow версии тестовых зависимостей и установка браузера заданы явно. Локально можно указать абсолютные пути `BV_JSDOM_PATH`, `BV_PLAYWRIGHT_PATH`, `BV_CHROMIUM_PATH` и, для сравнения типографики, `BV_FONT_CACHE`.

```sh
for suite in cta quiz faq; do node "scripts/tests/$suite.dom.mjs" || exit 1; done
for suite in cta prices locations visits release; do node "scripts/tests/$suite.browser.mjs" || exit 1; done
php server/tests/phone.test.php
php server/tests/handler.test.php
php server/tests/handler.test.php --browser
```

`BV_QA_OUTPUT` задаёт каталог для контрольных изображений вне `dist/`. Файлы заказчиков и доступы для тестов не нужны. Полная матрица выполнена локально, ключевые регрессии включены в CI перед сборкой архива.
